# سیستم مدیریت کتابخانه (Java)

یک پروژه‌ی پایه برای درس برنامه‌سازی پیشرفته، پیاده‌سازی‌شده با Java Swing و بدون کتابخانه‌ی خارجی.

## امکانات فعلی

- ثبت، ویرایش، جستجو و حذف کتاب
- ثبت، ویرایش، جستجو و حذف عضو
- جلوگیری از ثبت شابک تکراری و شماره دانشجویی تکراری
- ثبت امانت کتاب با مهلت ۱۴ روزه
- ثبت بازگشت کتاب و به‌روزرسانی تعداد نسخه‌های موجود
- نگهداری سابقه‌ی امانت‌ها و نمایش دیرکرد
- محاسبه‌ی جریمه‌ی دیرکرد با نرخ پایه‌ی ۱۰٬۰۰۰ تومان برای هر روز
- نمایش آمار خلاصه در بالای برنامه
- رابط گرافیکی فارسی و راست‌چین

## پیش‌نیاز

JDK 17 یا جدیدتر. برای بررسی نسخه‌ی جاوا می‌توان از این دستور استفاده کرد:

```bash
java -version
javac -version
```

## اجرا در ویندوز

فایل `run.bat` را اجرا کنید. این فایل ابتدا پروژه را کامپایل و سپس برنامه را اجرا می‌کند. در صورت اجرا از ترمینال نیز می‌توان در پوشه‌ی پروژه دستور زیر را زد:

```bat
run.bat
```

## اجرا در Linux یا macOS

```bash
./run.sh
```

## نکته‌ی مهم درباره‌ی اطلاعات

این نسخه عمداً دیتابیس ندارد؛ کتاب‌ها، اعضا و امانت‌ها در حافظه نگهداری می‌شوند و با بستن برنامه پاک می‌شوند. این وضعیت برای نسخه‌ی پایه در نظر گرفته شده تا مرحله‌ی بعد بتوان SQLite یا دیتابیس موردنظر استاد را اضافه کرد.

## ساختار کد

```text
src/main/java/com/example/library/
├── Main.java
├── model/
│   ├── Book.java
│   ├── Member.java
│   └── Loan.java
├── service/
│   └── LibraryService.java
└── ui/
    └── MainFrame.java
```

- `model`: کلاس‌های داده و وضعیت موجودیت‌ها
- `service`: قوانین اصلی کتابخانه و اعتبارسنجی‌ها
- `ui`: رابط گرافیکی Swing
- `Main`: نقطه‌ی شروع برنامه

## قوانین ساده‌ی پروژه

- هر کتاب با شابک یکتا ثبت می‌شود.
- هر عضو با شماره‌ی دانشجویی یکتا ثبت می‌شود.
- تعداد نسخه‌ها نمی‌تواند کمتر از تعداد نسخه‌های امانت‌داده‌شده شود.
- حذف کتاب یا عضوی که سابقه‌ی امانت دارد برای حفظ سوابق مجاز نیست.
- نسخه‌ای که امانت داده شده باشد از فهرست نسخه‌های قابل امانت خارج می‌شود و هنگام بازگشت، دوباره موجود می‌شود.
