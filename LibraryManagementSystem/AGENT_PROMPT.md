# پرامپت پیشنهادی برای ادامه‌ی پروژه با ایجنت

این مخزن یک سیستم مدیریت کتابخانه با Java Swing است. ابتدا تمام فایل‌ها و ساختار فعلی را بخوان و برنامه را اجرا/کامپایل کن؛ سپس تغییرات خواسته‌شده را روی همین پروژه اعمال کن، نه اینکه پروژه‌ی جداگانه‌ای از صفر بسازی.

## وضعیت فعلی
- رابط گرافیکی فارسی و راست‌چین با سه بخش کتاب‌ها، اعضای کتابخانه و امانت/بازگشت
- کلاس‌های `Book`، `Member` و `Loan` در پوشه‌ی `model`
- قوانین کسب‌وکار در `LibraryService`
- رابط کاربری در `MainFrame`
- فعلاً هیچ دیتابیسی وجود ندارد و داده‌ها در حافظه ذخیره می‌شوند.

## هنگام اضافه‌کردن دیتابیس
1. رابط گرافیکی و امکانات فعلی را حفظ کن.
2. ذخیره‌سازی را به SQLite منتقل کن و برای اتصال JDBC از وابستگی مناسب استفاده کن.
3. ساخت دیتابیس و جدول‌ها را خودکار انجام بده؛ کاربر نباید لازم باشد SQL را دستی اجرا کند.
4. کتاب‌ها، اعضا و امانت‌ها پس از بستن و اجرای دوباره‌ی برنامه باقی بمانند.
5. عملیات امانت و بازگشت را طوری پیاده کن که موجودی کتاب و رکورد امانت ناسازگار نشوند؛ برای عملیات چندمرحله‌ای از transaction استفاده کن.
6. SQL را در کلاس رابط کاربری قرار نده. یک لایه‌ی Repository/DAO جدا ایجاد کن و `LibraryService` را از آن استفاده بده.
7. ورودی‌ها را اعتبارسنجی کن، خطاها را قابل‌فهم نمایش بده و از queryهای پارامتری (`PreparedStatement`) استفاده کن.
8. در پایان دستورهای دقیق build/run، وابستگی‌ها و فایل‌های تغییرکرده را توضیح بده و همه‌ی سورس‌ها را کامپایل کن.
